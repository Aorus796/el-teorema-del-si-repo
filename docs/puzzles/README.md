## Flujo de aprobación

1. Concepto.
2. Prototipo de papel.
3. Prueba independiente.
4. Verificación matemática.
5. Aprobado para programar.
6. Implementado.
7. Prueba integrada.
8. Cerrado.

## Ficha mínima

Cada archivo de puzle deberá incluir:

- Objetivo narrativo.
- Reglas y datos.
- Solución y soluciones alternativas.
- Interfaz.
- Estados.
- Validación.
- Reflexiones.
- Persistencia.
- Consecuencia.
- Riesgos.
- Casos de prueba.
- Resultados de playtesting.
