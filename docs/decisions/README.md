# Registros de decisiones de arquitectura y diseño

Las ADR documentan decisiones que resultaría costoso olvidar o revertir.

## Formato

Cada ADR debe contener:

- Estado.
- Contexto.
- Decisión.
- Consecuencias.
- Alternativas descartadas.
