# ADR-0003: el cuaderno registra evidencias, no soluciones

- **Estado:** Aceptada
- **Fecha:** 2026-07-24

## Contexto

El jugador puede necesitar varios días para completar los últimos puzles, pero automatizar las deducciones eliminaría el desafío.

## Decisión

El cuaderno conservará hechos, testimonios, símbolos, mapas y estados observados. No escribirá automáticamente la interpretación correcta ni la solución de los acertijos.

## Consecuencias

- Resulta posible retomar la partida después de varios días.
- El jugador sigue siendo responsable de relacionar la información.
- Los resúmenes deben limitarse a descubrimientos ya alcanzados.
